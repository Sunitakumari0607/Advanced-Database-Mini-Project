# Advanced Database Mini Project

## Automated SQL Query Migration using Large Language Models

This project presents an intelligent SQL translation system for migrating Oracle SQL queries to PostgreSQL.

### Features

- Oracle SQL to PostgreSQL query translation
- Feature-aware retrieval
- Confidence scoring
- Retrieval-Augmented Generation (RAG)
- Deterministic rule-based fallback
- SQL conversion interface

### Project Structure

- `Source Files/` — Project report, figures, and supporting files
- `sql_ui/` — SQL translation application source code
- `.gitignore` — Git ignored files configuration
